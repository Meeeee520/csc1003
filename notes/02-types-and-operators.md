# 02 类型、运算与字符串拼接

## 先算右边，再赋给左边

```java
double a = 7 / 5;          // 1.0：右边先做整数除法
double b = 7.0 / 5;        // 1.4
double c = (double) 7 / 5; // 1.4
double d = (double) (7 / 5); // 1.0：转换已经太晚
```

两个整数相除得到整数，结果向 0 截断：`7 / 5 == 1`，`-7 / 5 == -1`。
平均值写成 `(double) sum / count`，而不是只把接收变量声明成 double。

## 运算符

| 运算符 | 例子 | 结果 |
| --- | --- | --- |
| `+` | `7 + 5` | 12 |
| `-` | `7 - 5` | 2 |
| `*` | `7 * 5` | 35 |
| `/` | `17 / 5` | 3 |
| `%` | `17 % 5` | 2 |

本节算术优先级：括号 → 乘、除、取余 → 加、减。同级通常从左往右算。
`a % 2 == 0` 可判断整数是否为偶数。

`=` 是赋值；`==` 是比较。`>=`、`<=`、`!=` 分别表示大于等于、小于等于、不等于。

```java
boolean valid = a >= 1 && a <= 100;
```

`&&` 表示两边都成立，`||` 表示至少一边成立，`!` 表示取反。不能把范围写成 `1 <= a <= 100`。
布尔字面量必须小写：`true`、`false`。

## 加法遇到 String 会变成拼接

```java
System.out.println(1 + 2 + "abc");   // 3abc
System.out.println("abc" + 1 + 2);   // abc12
System.out.println("abc" + (1 + 2)); // abc3
```

从左往右看每一步：先遇到数字就做加法；某一步出现字符串就拼接。

## 类型转换与浮点数

```java
int x = (int) 3.9; // 3，截掉小数，不是四舍五入
```

浮点数使用二进制近似存储，`0.1 + 0.2` 可能不严格等于 `0.3`。
涉及近似计算时可按题目精度用 `Math.abs(a - b) < epsilon` 比较。
`printf("%.2f", value)` 只改变显示格式，不改变 value 本身。
