# 02 类型、运算与字符串拼接

## int 的大小与范围

Java 的 `int` 固定是 **32 位（4 字节）**的有符号整数，不会因为电脑是 32 位还是 64 位而改变。

```java
int score = 100;
System.out.println(Integer.BYTES);     // 4
System.out.println(Integer.SIZE);      // 32
System.out.println(Integer.MIN_VALUE); // -2147483648
System.out.println(Integer.MAX_VALUE); // 2147483647
```

- 1 字节等于 8 位，因此 32 位等于 4 字节。
- `int` 的范围是 `-2^31` 到 `2^31 - 1`。
- 超出范围继续运算可能发生溢出；Java 不会自动改用 `long`。

易错点：`int` 变量的值即使很小，类型仍占 4 字节。Java 规定的是类型宽度，不是“当前数值需要几位”。

## 先算右边，再赋给左边

```java
double a = 7 / 5;          // 1.0：右边先做整数除法
double b = 7.0 / 5;        // 1.4
double c = (double) 7 / 5; // 1.4
double d = (double) (7 / 5); // 1.0：转换已经太晚
```

两个整数相除得到整数，结果向 0 截断：`7 / 5 == 1`，`-7 / 5 == -1`。
平均值写成 `(double) sum / count`，而不是只把接收变量声明成 double。

复杂算式也要分段看每个子表达式的类型：

```java
double result = 3 * 0.5 + 3 / 2 * 0.5; // 2.0
```

其中 `3 * 0.5` 是 `1.5`，但 `3 / 2` 先按整数除法得到 `1`，再乘 `0.5` 得到 `0.5`，所以总和是 `2.0`。

## 运算符

| 运算符 | 例子 | 结果 |
| --- | --- | --- |
| `+` | `7 + 5` | 12 |
| `-` | `7 - 5` | 2 |
| `*` | `7 * 5` | 35 |
| `/` | `17 / 5` | 3 |
| `%` | `17 % 5` | 2 |

本节算术优先级：括号 → 乘、除、取余 → 加、减。同级通常从左往右算。
`a % 2 == 0` 可判断整数是否为偶数。

`=` 是赋值；`==` 是比较。`>=`、`<=`、`!=` 分别表示大于等于、小于等于、不等于。

```java
boolean valid = a >= 1 && a <= 100;
```

`&&` 表示两边都成立，`||` 表示至少一边成立，`!` 表示取反。不能把范围写成 `1 <= a <= 100`。
布尔字面量必须小写：`true`、`false`。

## 短路求值：先判断左边，再决定是否计算右边

`&&` 和 `||` 会从左往右求值，并在结果已经确定时跳过右侧表达式：

```java
if (n != 0 && total / n > 5) {
    System.out.println("平均值大于 5");
}

if (s != null && s.length() > 0) {
    System.out.println(s);
}
```

- `&&`：左边为 `false` 时，整个表达式必为 `false`，右边不再计算。
- `||`：左边为 `true` 时，整个表达式必为 `true`，右边不再计算。

这让左侧条件可以保护右侧操作：先确认 `n != 0`，才执行除法；先确认 `s != null`，才调用 `s.length()`。

易错点：保护条件必须写在左边。交换成 `total / n > 5 && n != 0`，程序可能在检查 `n` 之前就发生除零错误。

## 整数提升与溢出

Java 会先按表达式中操作数的类型进行运算，再把结果赋给左侧变量。两个 `int` 相乘仍是 `int` 运算；即使左侧是 `long`，也不能补救已经发生的溢出：

```java
int x = 50_000;

long wrong = x * x;         // 先按 int 计算，结果已经溢出
long right = (long) x * x;  // 先把一个操作数转为 long，结果为 2500000000
```

`byte`、`short`、`char` 参与普通算术时通常先提升为 `int`：

```java
byte a = 100;
byte b = 20;

int sum = a + b;           // 正确：a + b 的类型是 int
// byte c = a + b;         // 编译错误：不能自动把 int 缩小为 byte
```

易错点：

- 整数溢出不会自动改用 `long`，也不一定抛出异常。
- 要在运算发生前扩大类型，例如 `(long) x * x`；运算后再强转已经太晚。
- 缩小类型可能丢失信息，需要显式强转，并确认结果范围符合题意。

## 前置自增与后置自增

`i++` 和 `++i` 都会让 `i` 增加 1，区别在于表达式先使用哪个值：

- `i++`：先使用 `i` 的旧值，再把 `i` 加 1。
- `++i`：先把 `i` 加 1，再使用增加后的新值。

```java
int i = 2;
int a = i++; // a = 2，随后 i = 3
int b = ++i; // 先让 i = 4，再把 4 赋给 b
```

单独写成一行时，两者最终效果相同：

```java
i++;
++i;
```

但放进条件表达式时，判断使用的值不同。假设每段代码开始时 `i = 0`：

```java
while (i++ < 3) {
    System.out.println(i);
}
// 输出：1、2、3
// 循环结束后 i = 4
```

最后一次判断虽然 `3 < 3` 为假，但后置自增仍已执行，所以 `i` 从 3 变成 4。

```java
while (++i < 3) {
    System.out.println(i);
}
// 输出：1、2
// 循环结束后 i = 3
```

易错点：

- 不要把 `i++` 理解成“这一整行结束后才加 1”；更准确地说，它在本次表达式中提供旧值，同时变量本身完成加 1。
- `while` 的条件即使最终为假，也已经被求值，所以条件中的自增仍会发生。
- 循环更新位置单独写 `i++` 或 `++i` 通常没有区别；一旦它们参与赋值、比较或方法参数，就要区分旧值和新值。
- 避免写 `i = i++` 这类难读表达式；右侧产生旧值，最后赋值可能把自增后的结果覆盖。

## 加法遇到 String 会变成拼接

```java
System.out.println(1 + 23 + "45");   // 2445
System.out.println("1" + 23 + 45);   // 12345
System.out.println("abc" + (1 + 2)); // abc3
```

`+` 从左往右计算，但每一步是“数值加法”还是“字符串拼接”，取决于这一步的操作数：

- `1 + 23 + "45"`：先算 `1 + 23` 得到整数 `24`，再算 `24 + "45"`，结果是字符串 `"2445"`。
- `"1" + 23 + 45`：先拼成字符串 `"123"`；下一步左边已经是字符串，所以继续拼成 `"12345"`。
- `"abc" + (1 + 2)`：括号中的数值加法先得到 `3`，最后拼成 `"abc3"`。

易错点：一旦前面的计算结果已经是 `String`，后面的数字不会让它变回数值加法。需要先算数字时，用括号明确顺序。

## 类型转换与浮点数

```java
int x = (int) 3.9; // 3，截掉小数，不是四舍五入
```

浮点数使用二进制近似存储，`0.1 + 0.2` 可能不严格等于 `0.3`。
涉及近似计算时可按题目精度用 `Math.abs(a - b) < epsilon` 比较。
`printf("%.2f", value)` 只改变显示格式，不改变 value 本身。

### 保留两位小数：显示格式和数值处理不同

如果要求输出固定两位小数，最直接的是使用格式化输出：

```java
double average = 3.1;
System.out.printf("Average: %.2f%n", average); // Average: 3.10
String text = String.format("%.2f", average); // "3.10"
```

- `printf` 直接输出格式化结果，`%n` 表示换行。
- `String.format` 返回一个新的 String，适合先保存、之后再使用。
- `%.2f` 会按两位小数显示：位数不足时补 0，位数超过时按格式化规则舍入。
- 两种写法都不会改变 `average` 原来的值。

如果后续计算需要一个舍入后的数值，可以写：

```java
double rounded = Math.round(average * 100) / 100.0;
```

易错点：`Math.round` 得到的是数值，不负责固定显示位数。普通输出时，`3.10` 仍可能显示成 `3.1`；需要固定两位时仍应使用 `printf` 或 `String.format`。浮点数仍采用二进制近似存储，不适合直接替代精确的金额计算。

### 算式里出现 `double` 后，结果也是 `double`

```java
int x = 13;
double a = x * 1.5 / 3;   // 6.5，正确
// int b = x * 1.5 / 3;   // 编译错误：double 不能自动变成 int
int c = (int) (x * 1.5 / 3); // 6，明确截掉小数部分
```

Java 可以把 `int` 自动扩大为 `double`，因为这通常不会丢失整数部分；反过来可能丢失小数，所以必须显式强转。强转表示“我接受信息丢失”，不会四舍五入；需要四舍五入时可按题目要求使用 `Math.round()`。

易错点：强转整个算式时，括号要包住完整结果。`(int) x * 1.5 / 3` 仍会因为 `1.5` 变成 `double`。
